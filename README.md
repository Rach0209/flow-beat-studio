# ◈ Flow Beat Studio

분위기를 문장으로 입력하면 **Gemini AI**가 16스텝 신스 패턴을 작곡하고, 브라우저의 **Web Audio**가 실시간으로 연주하는 BGM 웹앱입니다.
서버·빌드 도구 없이 정적 파일만으로 동작합니다.

🔗 **데모:** https://rach0209.github.io/flow-beat-studio/

## 기능

- **AI 트랙 생성** — 프롬프트 → Gemini가 BPM·스케일·파형·이펙트·5트랙 패턴을 JSON으로 생성
- **로컬 엔진 폴백** — API 키가 없거나 호출이 실패하면 키워드 기반 로컬 작곡기로 자동 전환
- **16스텝 시퀀서** — Kick / Snare / Hihat / Chord / Lead, 채널별 볼륨·뮤트
- **피아노롤 에디터** — 리드 멜로디를 반음 단위(C2~C6) × 16스텝 격자에서 클릭·드래그로 입력·삭제 (입력 시 미리듣기). AI·프리셋 결과도 그대로 보이고 수정할 수 있습니다.
- **키보드 모드** — 컴퓨터 키보드를 피아노처럼 써서 스텝 입력. 1옥타브 건반에 단축키가 표시되며 한글 입력 상태에서도 동작합니다.

  | 키 | 동작 |
  |---|---|
  | `A S D F G H J K` | 흰 건반 (도 레 미 파 솔 라 시 도) |
  | `W E` `T Y U` | 검은 건반 (도# 레# / 파# 솔# 라#) |
  | `Z` / `X` (또는 `↓` / `↑`) | 옥타브 내리기 / 올리기 (옥타브 2~5) |
  | `→` 또는 `Space` / `←` | 다음 칸 / 이전 칸 (`Home` / `End`: 처음 / 끝 칸) |
  | `Backspace` / `Delete` | 현재 칸의 음 지우기 |
  | `Esc` | 키보드 모드 종료 |

  "입력 후 자동으로 다음 칸" 옵션을 켜면 음을 칠 때마다 커서가 앞으로 이동합니다.
- **MIDI 내보내기** — 드럼·코드·리드를 표준 MIDI 파일(.mid, 8마디)로 저장해 DAW에서 이어서 편집
- **신스 & 앰비언스** — BPM, 스케일, 파형, Cutoff, 리버브, 바이닐 노이즈, 빗소리
- **WAV 내보내기** — 8마디를 44.1kHz 스테레오 16-bit로 렌더링
- **프리셋 5종** — Lo-Fi, Synthwave, Ambient, City Pop, Minimal Techno

> Gemini는 오디오를 만들지 않고 "악보(패턴 JSON)"만 만듭니다. 소리는 내장 신스 엔진이 합성합니다.

## 사용법

1. 데모에 접속해 프리셋을 고르고 **▶ 재생**
2. AI 작곡을 쓰려면 우측 상단 버튼에서 [Google AI Studio](https://aistudio.google.com/apikey) API 키를 입력 (무료 티어 사용 가능)
3. 프롬프트를 입력하고 **✨ AI 트랙 생성**

키는 **본인 브라우저의 `localStorage`에만** 저장되고 Google API 호출에만 쓰입니다. 저장소에는 키가 없습니다.
지원 모델: `gemini-3.8-flash`(기본), `gemini-3.6-flash`, `gemini-3.5-flash-lite`

> 선택: Google OAuth Client ID를 입력하면 로그인 버튼으로 프로필(이름·아바타)을 표시할 수 있습니다. 표시용이며 Gemini 호출과는 무관합니다.
> Cloud Console의 **승인된 JavaScript 원본**에 `https://rach0209.github.io`를 추가해야 합니다.

## 알려진 제한

- 피아노롤은 리드 트랙 전용이며 한 스텝에 음 하나(단음), 음 길이는 고정입니다. 코드·드럼은 스텝 격자에서만 편집합니다.
- 리드 음은 절대 음높이(MIDI 번호)로 저장되므로, 스케일을 바꿔도 이미 입력한 리드 음은 따라 움직이지 않습니다(코드만 바뀝니다). AI·프리셋의 음은 불러올 때 현재 스케일 기준으로 변환됩니다.
- MIDI 내보내기의 악기(프로그램 번호)는 GM 기준 근사 매핑이라 DAW에서 음색을 바꿔 쓰세요.
- 스케일은 4종, 코드 진행은 4마디 순환으로 고정이며 모델 목록은 하드코딩되어 있습니다.
- 앱 코드는 MIT이지만, Gemini API·Google 로그인 사용에는 각각 Google의 약관과 정책이 적용됩니다.
